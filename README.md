# snapmark

A tiny, local-first bookmark and snippet manager for the terminal.

## Usage

- `snapmark add rust https://rust-lang.org`
- `snapmark list`
- `snapmark search rust`
- `snapmark get rust`
- `snapmark rm rust`

Local JSON storage. No account, server, API key, or cloud sync.
